# TL1_02_05 敵キャラSpawnPoint

Blender上でプレイヤーと敵の出現位置を別々のシンボルとして配置し、JSONを介してCG2へ反映する機能です。

## 実装した内容

- `SpawnNames`にプレイヤー／敵の複製元名、配置名、モデルファイル名をまとめて管理
- OBJ読込処理を`load_obj()`へ共通化し、種類を追加しやすい構成へ変更
- 同じモデルは初回だけ読み込み、2個目以降はメッシュデータを共有して複製
- プレイヤー用と敵用のシンボル作成オペレーターを追加
- `MyMenu`から両方のシンボルを個別に作成可能
- シンボルへ`PlayerSpawn`／`EnemySpawn`の`type`と`file_name`を設定
- 既存のエクスポート処理を利用し、両方の種類とTransformをJSONへ出力
- C++側へ`EnemySpawnData`と`enemies`配列を追加
- 親子階層を含めて`EnemySpawn`を再帰的に検索し、ファイル名・座標・回転を読み込み
- `file_name`に対応するモデルを取得し、敵をJSONの座標・回転へ配置
- モデルを取得できない場合は既存の敵モデルを使用するフォールバックを追加

## 動作確認

- Blender 4.4.1のバックグラウンド実行で、アドオン登録、プレイヤー1個・敵2個の配置、モデル共有、JSON出力、登録解除を確認
- JSONに`type: "PlayerSpawn"`が1件、`type: "EnemySpawn"`が2件出力されることを確認
- 各SpawnPointの`file_name`、座標、回転がJSONへ出力されることを確認
- CG2をDebug x64／Release x64でビルドし、どちらも警告0・エラー0を確認
- Release実行ファイルが15秒以上正常に起動することを確認

## ファイル構成

- Blenderアドオン本体: リポジトリ直下の`level_editor`フォルダ
- ゲーム側の変更ファイル: `TL1_02_05/project`以下

`project`以下は、CG2の`TL1課題用`ブランチを基準に変更したファイルを元のパスのまま収録しています。このフォルダだけでは単独ビルドできないため、完全な実行プロジェクトは下記のCG2リポジトリを参照してください。
